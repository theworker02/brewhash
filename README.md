# brewhash

Brew config/hash key checks for twelve-factor services.

**Site:** https://theworker02.github.io/brewhash/

## Install / run

```bash
git clone https://github.com/theworker02/brewhash.git
cd brewhash
node src/cli.js
node --test
```
